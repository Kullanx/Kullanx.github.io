Quick Start

Install in 60 seconds

No complicated setup. Download, extract, install dependencies, and you're ready to grind.

Windows Terminal — setup.ps1 
# 1. Clone the repository
git clone https://github.com/Kullaners/TinyKullan.git
cd TinyKullan

# 2. Run the automatic dependency installer
python "python installer.bat"

# 3. Launch the app (silent mode — no console)
start TinyKullan.vbs

# 4. Press F5 to record, F6 to play, F7 to loop! 🚀
